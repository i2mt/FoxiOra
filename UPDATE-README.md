# FoxiOra v12.30 — simpler everyday tasks

Shift editing is available directly on Today's shift card and on each saved shift beneath the calendar. Selected-day details come before monthly hours. Adding a shift is distinct from changing an existing one, including when someone works at multiple workplaces. Manual entry now opens on the calendar and returns to the saved date. Opening a second editor preserves the first draft and exposes Continue editing; each draft retains its own shift identity and fields.

The roster table comes first, with search on demand, colleague lookup folded underneath, and monthly hours below. Date headers open the colleague lookup for that date. Name correction lives with colleague identity management. Opening the table exits a stale scan-correction subview.

Roster entry starts with Photo, File or Manual. Photo-specific fields are deferred, names remain optional, and photo/date repair tools are grouped. File preview prioritizes choosing your row and seeing the data, explains why Save is unavailable, highlights your row, and has an explicit Cancel. An unfinished file cannot be silently reassigned to another workplace. Scan review also has a Cancel that leaves saved schedules unchanged.

Agreed one-way handovers now have an explicit preview and Save action, updating your saved duty to off and the colleague's duty to the transferred/combined code. Recording rechecks current eligibility, restrictions, surrounding roster, rest and night recovery; storage failure rolls back the change. Undo restores both people. Request copying remains a separate action. No message is sent by the app.

Incomplete free-time results identify the workplace/date and offer direct correction or a whole-roster import. Swap results expose a direct recovery action. Available time and the exact interval about to be booked are shown separately. Monthly missing/unclear counts are labelled as roster cells rather than distinct days across multiple workplaces.

Colleague accepted shifts, optional hour/day limits, identity tools and schedule comparison have separate homes. The duplicate no-combined switch is removed. Changing a custom accepted-shift list explicitly replaces that related restriction; unrelated limits remain. Swap selection starts with one shift, with multiple selection available on demand.

Settings retain one full-width item per row, Support above Tour/Install, and the FoxiOra logo, Latin version and developer credit at the bottom. One main settings section opens at a time; saving is labelled automatic. The workplace entry is named for workplaces and shift hours, and scanner wording refers to scanning. Symbol aliases/productivity rules are secondary; allowed combinations use checkboxes with a two-symbol builder. A combination-version marker preserves explicit DN exclusions while the legacy default still gains DN.

The seven short intro stops now practice choosing an input method and correcting/saving a sample, then introduce Today/calendar, an interactive swap, planning and personalization. Photo, file and manual practice work without uploading a file or contacting an OCR service. Sample changes never enter the real schedule or undo history, and existing file/photo/editor drafts are restored on exit. The welcome artwork/animation, developer credit, reduced-motion support and separate guide/app panes remain. Completion returns to Today or first setup and closes sample settings.

Feedback occupies a header row instead of covering form buttons. Install/update offers wait during unfinished editing/import/review work. Later/Never installation options, Latin versions, explicit update approval, approved FoxiOra artwork and visible loading fill remain.
