# FoxiOra v12.37 interaction review

The main path should offer one understandable next action. Secondary tools stay reachable; information needed to avoid data loss or an incorrect schedule stays visible.

| Area | Main path | Secondary controls / safeguards |
| --- | --- | --- |
| Start / Today | Add roster, see next shift, open calendar | Removed duplicate shift edit and duplicate empty-state manual entry |
| Add roster | Choose photo, file or manual entry | Explicit action labels; existing unfinished-import protection |
| Photo reading | Progress and Stop; choose your row | Existing cancellation and replacement-photo recovery |
| Unclear symbols | Friendly question, one crop, six common choices | More symbols, skip, full month and repairs; Undo retained |
| Finish import | Review identity and choose own/all rows, then save | Name editing under More; pending dates/symbols and duplicate warnings stay visible |
| File import | Choose row/month and map unfamiliar symbols | Full table preview folded; required mappings and errors visible |
| Colleague extraction | Stay on import until complete | Stop available; end in monthly calendar |
| Monthly calendar | Tap day to edit; save the chosen shift | Existing multiple-workplace selection and unsaved drafts; legend folded |
| Whole roster | Swipe through the entire month immediately | Sticky name crops; optional import/preferences/symbol tools folded |
| Shift swapping | Choose a shift, then find options | Multi-selection/preferences/request text folded; conflicts and confirmation retained |
| Free time / trips | Choose duration, find free time | Start date/time and searches involving shift changes expandable |
| Settings | One row per category, personalization and recovery accessible | Tighter spacing; contact/tutorial/install/footer retained; short screens may scroll |
| Tutorial / updates | Existing guided preview and explicit update choice | No forced reload or changes to installation choices |

Use task verbs for actions (add, choose, edit, save), short nouns for navigation, and friendly questions where the user must decide. Do not hide overwrite, date, overlap or unreadable-shift warnings as optional detail. Keep advanced capabilities available without making them prerequisites for ordinary use.
