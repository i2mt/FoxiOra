# FoxiOra v12.38 controls and navigation

Use one clear next action for the ordinary task. A disclosure should identify a related set of adjustments; it should not wrap a single action or duplicate another generic menu.

| Section | Direct path | Adjustments and secondary tools |
| --- | --- | --- |
| Today | Add roster, next shift, calendar | No duplicate shift editor |
| Add roster | Photo / file / manual; labelled progress | Pending checkpoint offers Continue or explicit discard |
| Photo review | One crop and common symbols; Undo | “Photo, name & dates” contains identity/source repairs; “Review other days” contains full-day review; extra symbols have their own explicit label |
| Import completion | Scope and Save | Uncertainty/date/overwrite warnings stay visible; successful save opens the correct monthly calendar |
| File preview | Own row, required dates and mappings, Save | Named full-table preview and file-heading controls; no generic More wrapper |
| Monthly calendar | Tap day, gentle scroll to editor, return to calendar | Existing unsaved drafts retained; legend specifically labelled |
| Roster grid | Immediate whole-month scrolling, pinned names/dates | No pencil row; names themselves edit; “Manage this roster” groups colleague-photo/file input separately from limits and symbol/hour settings |
| Shift swap | Calendar/list, direct multi-selection, suggestions | Direct colleague-limits and roster links; direct request-copy action on a result; specific conflict/review reasons |
| Colleague limits | Person, permitted shifts and exclusions | Named day/hour constraints and identity/duplicate controls; suggestion rule names its effect |
| Free time / trips | Duration and Find | Specifically labelled start-date/time and searches requiring shift changes |
| Settings | Existing single-column categories | Workplaces, appearance/language, calendar, scanner, alerts, backup; contact/tutorial/install remain separate actions |

No OCR model change, threshold change, automatic curved-paper flattening or participant study is claimed. Advanced tools and larger text may require vertical scrolling. Usability sessions are specified in USABILITY-TEST.md.
