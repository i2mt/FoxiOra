Verified results are included as JSON and the regression log. Optional browser harnesses require Playwright with Chromium. Install Playwright in the app or its parent directory, then run `node verification/navigation-browser.cjs`. To rerun crop evaluation, extract the training archive beside the app folder or set FOXIORA_DATASET to its qa-v12.15 folder, then run `node verification/cells-browser.cjs v12.15 repeated`. FOXIORA_APP can point to another app build for comparison. These tests use a local HTTP server. Browser/screenshot output is written in verification; none of the private original pages are bundled.
